# 2026-10-15 — The People tab is named Add People, and its button reads Add

The owner asked on 15 Oct, using the application, for changes to the People screens, and chose
from a clickable preview what the Branch screen keeps.

## The ruling

1. **The `People` tab of People is named *Add People*** (owner, 2026-10-15), because that is
   what the tab is for. The sidebar item stays `People`, and the tab is the same screen as
   before (decision 0288); only its label changes. Tabs keep title case (decision 0332).
2. **The button that opens the form reads *Add*** (owner, 2026-10-15), the tab already saying
   what is added. Its accessible name stays *Add a person*, which holds the word shown, and the
   form it opens keeps that heading. Who is offered it is unchanged (decision 0350).
3. **The Branch screen's focus block no longer says who the person is pastored by** (owner,
   2026-10-15). The breadcrumb above it already names that person. Where nobody pastors them,
   the block still says why (decision 0270).
4. **The Branch screen keeps its breadcrumb and its search** (owner, 2026-10-15, choosing A from
   a preview of trail and search, search only, or neither). The search finds a person to open
   or move, and the breadcrumb is the way back up the tree.

This narrows decision 0252's point 1 by one line and changes nothing else on either screen.
