# 2026-10-15 — The People tab is named Add People, and the Branch screen loses its trail and search

The owner asked on 15 Oct, using the application, for three changes to the People screens.

## The ruling

1. **The `People` tab of People is named *Add People*** (owner, 2026-10-15), because that is
   what the tab is for. The sidebar item stays `People`, and the tab is the same screen as
   before (decision 0288); only its label changes. Tabs keep title case (decision 0332).
2. **The Branch screen carries no breadcrumb and no search** (owner, 2026-10-15). It repeated
   what the People tab and the focus block already show. A person is still found from Add
   People, and the reader goes back up the tree with the browser's Back.
3. **The focus block no longer says who the person is pastored by** (owner, 2026-10-15). It
   still names the person and, where nobody pastors them, why (decision 0270).
4. **The button that opens the form reads *Add*** (owner, 2026-10-15), the tab already saying
   what is added. Its accessible name stays *Add a person*, which holds the word shown, and the
   form it opens keeps that heading. Who is offered it is unchanged (decision 0350).

This narrows decision 0252's points 1 and 6, and changes nothing else on either screen.
