# 2026-09-24 — A Cell created in error opens nothing

Section 27 derives Open a cell from the earliest leadership of a Cell a `NEW_CELL` request
names, and says a goal reached does not lapse. Section 10 closes a Cell `CREATED_IN_ERROR`
when it should never have existed, which is also its remedy for a request approved in error.
Nothing said which of the two wins, and a derived goal has no confirmation to withdraw.

The owner ruled on it.

## The ruling

**A Cell closed `CREATED_IN_ERROR` does not count toward Open a cell.** The closure is the
correction of the record the goal rests on, so it unmakes a goal reached through that Cell,
as withdrawing any record a derived goal rests on does. A Cell closed for any other reason
still counts.

## Why

A goal reached stays reached because a milestone is not a level somebody falls out of. That
rule was never a shield for a record the church says was wrong, and this closure reason says
exactly that. The other reasons say the Cell existed and ended.
