# 2026-10-14 — A Record tab with nothing in it shows no count

Decision 0290 put each Record list's count in a box on its button. Most of the time most of
the lists are empty, and a row of zeros hid the lists that had work in them. The owner chose
this on 14 Oct from real screenshots.

## The ruling

**A Record tab whose count is 0 shows no box**: "Pending DCC Reports" rather than "Pending DCC
Reports 0". A count above 0 keeps its box, as before. This holds for every Record tab, the
Senior Pastors' Update Record included.

## Why

The numbers that matter stand out when the empty lists are quiet. The cost, accepted: a tab
whose count is still being read also shows no box, so for a moment an empty list and one
still loading look alike. A count that could not be read still puts the failure notice at the
top of the page. Rejected: removing every count, which takes away how much is outstanding,
the figure an Admin or a Full view leader opens the page for.
