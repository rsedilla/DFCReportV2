# 2026-10-06 — The Network tab is named Branch

Section 4 makes a Network the Men's or the Women's Network. The People tab called *Network*,
and the person page's button *Pastoral network*, used the same word for one person's branch of
the pastoral tree, on screens that also say *Men's Network* and *Network root*. The owner chose
this version from screenshots of both places, beside their Claude Design, which uses the word
both ways too.

## The ruling

**1. The tab is *Branch*, and the screen it opens is the Branch screen.** It is the screen
decisions 0252 and 0288 call the Network screen, and nothing about it changes but the name.

**2. The person page's button is *Where they sit*,** for the page showing that person's place in
the pastoral tree.

**3. Only the labels change.** Addresses, routes and figures stay as they are.

## Why

*Network* then only ever means the Men's or the Women's Network. Earlier rulings and open items
say "the Network screen"; they mean the Branch screen.
