# 2026-11-05 — The sidebar shows each item's icon

Since decision 0439 the phone's tab bar has shown each item's icon over its word, while the
sidebar on a wider screen dropped the icon and showed the word alone. On 2026-11-05 the owner
asked for icons before the sidebar's links, and chose from screenshots of the sidebar today and
with icons, for a Full view leader, a Senior Pastor, the Admin and a Leader, beside the phone.

## The ruling

**The sidebar shows each item's icon before its words**: the icon the tab bar already gives the
item, 20px, in the words' colour, white on the current row and mint on the others, with no pill.
The current row is marked as before, by its darker emerald and the white bar down its left
(decision 0423), so the icon adds no new way of telling which item is current. The icon is
hidden from a screen reader, which reads the item's words alone, and the whole row stays the
link. *Account and session*, under the person's name, stays a plain link with no icon. The phone's
tab bar is unchanged.

## Why

The guidance read for this agrees that a navigation icon helps when it stands beside its word
rather than in place of it, and that it belongs on the top-level items only. Using the tab bar's
own icons means a person learns one picture per item on every screen size.
