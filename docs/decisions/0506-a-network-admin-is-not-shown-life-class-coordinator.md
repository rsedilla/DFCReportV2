# 2026-11-22 — A Network Admin is not shown Life Class Coordinator

Owner ruling of 2026-11-22: "do not show to network admins the life class tickbox". Decision
0469 shows a Network Admin the ticks only the whole-church Admin gives, *Approves Cells* and
*Moves people*, when they are on, so that they know why they cannot clear Full view. Decision
0501 added *Life Class Coordinator* beside them, and the screens showed it the same way.

**1. A Network Admin is not shown whether a Leader account is ticked *Life Class Coordinator***,
on a person's Account view or in the Admin area's Accounts list. The school is the whole
church's, run by the Admin and the Registrar (Section 29), and coordinating it is not a Network
Admin's business.

**2. The tick still holds Full view on.** Clearing Full view clears *Life Class Coordinator*
(Section 7), so a Network Admin still may not clear Full view while it is on. Where it is the
only such tick, the Account view says *Only the Admin clears this.*, naming nothing; where
*Approves Cells* or *Moves people* is on as well, it names those as before.

This is what the screens show. The account read still carries the tick to a Network Admin, as
it carries the other two.
