# 2026-09-22 — One sidebar order for every account

Decision 0245 gave the two Senior Pastors and Admin their own order, `Reports · Record ·
Network · People · Cells`. Using the live application as Admin, the owner asked for the
order their design draws for everyone. The owner chose this answer from a drawing of it
beside the design's version, in which everyone would also land on `Record`.

## The ruling

**Every account sees `Record · Reports · People · Cells · Network`.** `Growth` joins between
`Cells` and `Network` when it is built.

**Where a person lands is unchanged.** An account holding `reports.view_subtree` at
`WHOLE_CHURCH` still lands on `Reports`, and every other account on `Record` (decision 0245).

## Why

The sidebar reads the same for every account, so a Senior Pastor sitting with a leader sees
the same list the leader does. Landing is kept apart from the order because church-wide
figures are still what those accounts come for.
